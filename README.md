# Exercícios de Python

Atividades do curso de Python: exercícios de estruturas de repetição, condicionais, tuplas e listas, feitos durante meus estudos de fundamentos da linguagem.

## Como executar

Requer Python 3.6+.

```bash
python exercicios/ex046.py
```
